# ML_projects
This is a Linear Regression model for an advertising company with three Target variables.TV, Radio, Newspaper. 
The customer wants to know which domain makes more profit. So that he can invest accordingly.


This repository contains my machine learning models, including data preprocessing pipelines, helper utility scripts, and model evaluation workflows.

## Features
* Automated function parsing scripts
* Custom utility helpers (`helper.py`)
* Linear Regression Model Notebook (`LinearRegg_model.ipynb`)
